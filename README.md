# 🌸 Tharunya Events

A modern and responsive **Event Management Website** designed to showcase event planning and decoration services. The website provides information about different event services, a gallery of previous events, booking functionality, and contact details.

## ✨ Features

* 🏠 **Home Page** – Introduction to Tharunya Events
* 💍 **Services** – Different event management and decoration services
* 📖 **About Us** – Information about the event management team
* 🖼️ **Gallery** – Collection of event images
* 📅 **Booking Page** – Allows users to submit event booking details
* 📞 **Contact Page** – Contact information and enquiry section
* 📱 **Responsive Design** – Works across desktop, tablet, and mobile screens
* ✨ **CSS Animations** – Smooth animations and visual effects
* 🎨 **Pastel-themed UI** – Elegant and attractive event-management design

## 🎉 Events Covered

The website showcases services for different types of events, including:

* 💒 Weddings
* 🎂 Birthdays
* 💍 Engagements
* 🎊 Anniversaries
* 👶 Baby Showers

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/tharunyareddy01/Tharunya-Events.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd Tharunya-Events
```

### 3. Run the website

Since this is a frontend project, you can simply open:

```text
index.html
```

in your browser.

You can also use **VS Code Live Server** for a better development experience.
